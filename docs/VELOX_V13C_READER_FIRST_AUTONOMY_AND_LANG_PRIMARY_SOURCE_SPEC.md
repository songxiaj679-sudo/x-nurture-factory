# VELOX V13-C: 初見が止まらない日本語と、読者の言語の一次情報

## 0. 前提
正は `AGENTS.md` の Sections 1–6。個別の言い回し、業種、トピックは書かない。新しいモデル呼び出しと追加クロールはしない。安全線、批評の 400 字未満、検証済み URL の送信時隔離は維持する。`commit` と `push` はしない。

## 1. 検索
言語は問わない。検索には、別ドメインの一次原典を3〜5件返すよう頼む。通過後は1ドメイン1件、Firecrawl に渡すのは最大3件で、本文が取れた最初の1件で止める。公式ドキュメント、公式ブログ、調査、統計、公開リポジトリ、関連論文。事業領域から外れた論文と、初心者向けのまとめは落とす。

`isPrimarySource()` は、名前に「論文」が無くても公式発信と調査レポートを通す。`arxiv` と `doi` のホストは、その分野の原典として残す。パスの `paper` と、名前だけの「論文」では通さない。初心者向けのまとめはこれまで通り落とす。

## 2. 引き算
外すのは次の4つ。中学生向けの言い換え、候補指示の「平易な言葉で書く」、学問名の前置き禁止、出典名を必ず残す義務。

代わりに、読者が普段使うカタカナや基本語を子ども向けに言い換えず、英語の一次情報も直訳せず、実務家の日本語で書く。
