# VELOX V13: 一次原典を、困っている人の言葉へ訳す

## 0. 前提
正は `AGENTS.md` の Sections 1–6。秘密、生 URL、顧客メールは出さない。`git push`、`prepareNextPost`、`X_MEDIA_WRITE_ENABLED` の変更はしない。再起動は `x-shop` だけ。特定の業種や題名は埋め込まない。新しい LLM 呼び出しと追加クロールは増やさない。週次上限、未使用カードのスキップ、全文と生 URL を保存しないこと、既存の安全線は維持する。待機予約 `job_next_eebd4cef-7b1f-4de6-a665-298b6a2133f7` は上書きしない。

## 1. 問いと原典
`selectArticleUrls()` は、顧客の `icpSummary` と `domainProblems` から、その分野の人が噂のまま困っている疑問を1つ選ぶ。検索は既存の1回のまま。Firecrawl の前に、URL と題名だけで初心者向けのまとめ（コツ7選、完全ガイド、基本設計の解説）を外す。残すのは公式仕様、統計、ガイドライン、論文、公開コード、リリースノート、調査報告と判定できるものだけ。最大3件で、ドメインが違うものを優先する。1件も無ければクロールしない。

## 2. カードの契約
`buildCard()` は `actionableTakeaway` を必須にしない。`readerQuestion`、`coreFact`、`mechanism`、`plainTranslation` を持ち、`plainTranslation` は作業命令にしない。古いカードは `actionableTakeaway` だけで読める。外部メモのラベル「一手」は使わない。新規カードは疑問、事実、仕組み、訳、思い込みを渡す。

## 3. 403 の次候補
一次原典は最大3件まで残し、ドメインが違うものを先に置く。Firecrawl が 403 か空本文なら次の候補を読む。本文が取れた最初の1件だけでカードを作り、そこで止める。週次の収集上限と、1回の収集で保存するカードは1件のまま。

## 4. 主語と結び
外部メモは、出典名を本文に残し、訳で終えるよう書く。確認手順や直しどころでは終えない。執筆側も、投稿前の確認や「いいね・コメント・シェアの仕分け」で締めない。調査に触れるときは出典名と、誰が何を調べたかを残す。「ただ研究を読むと」「チームでは」のように、何の研究か誰の話かを消さない。

## 5. 検証
新規テスト、既存の原典テスト、構文、インライン script、全スイート、`x-shop` 再起動、HTTP、待機予約、本番 DB へ書かない一気通貫の dry-run。
