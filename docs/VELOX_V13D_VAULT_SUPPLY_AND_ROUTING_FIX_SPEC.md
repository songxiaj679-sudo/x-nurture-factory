# VELOX V13-D: 在庫が空のときの収集と、一次原典を捨てない経路

執筆と採点の文面は変えない。変えるのは供給と経路だけ。

未使用の V13 カード（`plainTranslation` があり `usedCount === 0`）が 0 枚で、週次上限と月間クロール枠に空きがあるときは、プランの長い間隔ではなく 3 時間だけ空ければ収集する。週次上限、月間予算、未使用 6 枚での停止はそのまま。

`ring1` と `ring2` で使える一次原典カードがあるときは、Bandit が `dossier` を引いてもカードを使う。`dossier` はカードが無いときだけ。`ring3` と報酬計算は変えない。

`plainTranslation` が無く `usedCount >= 1` の旧カードは、次の投稿に選ばない。

`isPrimarySource()` は、まとめ・N選・入門・完全ガイドをこれまで通り落とす。タイトルに特定の単語が無いだけの安全な URL は残す。名前だけの「論文」と、パスが `/paper` だけのページは残さない。SNS・ログイン・規約も残さない。通過後は別ドメイン最大 3 件。

収集が空で終わったときは、`search_error` / `no_candidates` / `budget` / `scrape_empty` / `card_null` のどれかを、件数と HTTP ステータスだけ 1 行で出す。URL は出さない。
