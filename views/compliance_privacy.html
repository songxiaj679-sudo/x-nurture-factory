プライバシーポリシー

個人事業主 松下 駿介（VeloxPost Cloud 運営者）は、個人情報保護に関する法令を守り、次のとおりプライバシーポリシーを定めます。

1. 取得する情報

  • アカウント情報（メールアドレス、ユーザーID、表示名）
  • Google または X のログインで提供される基本プロフィール
  • X公式APIの認証情報（AES-256-GCM 暗号化方式で保存）
  • 投稿ログと、公式APIから取得できる反応指標

2. 利用目的

サービスの提供、投稿案の作成と予約、不正利用の防止、問い合わせ対応に利用します。

3. 安全管理

認証情報は AES-256-GCM 暗号化方式で保存し、アクセスを制限します。

4. 第三者提供

サービス提供に必要な外部委託と API 連携（X Corp. の公式 API、Stripe 決済、Firebase / Google Cloud、xAI API、Anthropic API（設定時）、OpenAI API（設定時）、Firecrawl API（設定時）、Langfuse（設定時・運用品質計測））および法令に基づく要請を除き、個人情報を第三者へ提供しません。

5. お問い合わせ

support@veloxpostapp.com

Privacy Policy

Shunsuke Matsushita, a sole proprietor and the operator of VeloxPost Cloud, handles personal information under Japanese privacy law.

1. Information we receive

  • Account details such as email, user ID, and display name
  • Basic profile data from Google or X sign-in
  • Official X API credentials, stored with AES-256-GCM encryption
  • Post logs and metrics returned by the official API

2. Purpose

We use this information to run the service, draft and schedule posts, prevent abuse, and answer support requests.

3. Safeguards

Credentials are stored with AES-256-GCM encryption and restricted access.

4. Sharing

We do not share personal information with other parties except for processors required to provide the service (X Corp. official API, Stripe, Firebase / Google Cloud, xAI API, Anthropic API when configured, OpenAI API when configured, Firecrawl API when configured, and Langfuse (when configured, operational quality telemetry)) and disclosures required by law.
