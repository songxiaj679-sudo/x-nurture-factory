📘 VELOX 使い方ガイド

初期はシンプルにおまかせ、こだわりたい部分だけあとから調整できます。

1. はじめの3ステップ（約3分）
  1. Xアカウントを連携：「初期設定」からX公式画面でログイン許可するだけです（パスワード入力は不要）。
  2. URLまたはアカウント像を入力：紹介したいサイトURLか、「どんなアカウントにしたいか」のどちらか1つ以上を保存します。
  3. 「自動運用を開始する」を押す：これだけで次の時間枠（08:30 / 12:30 / 17:30 / 20:00 / 22:30）に向けて次の1本が自動準備されます。
2. なぜ「次の1本だけ」予約されるの？

何十本も先に作り溜めるのではなく、投稿後の実際の反応（保存数や表示回数）を毎回確認してから次の1本を組み直すためです。

  • ✏️ 少し直す：予定時刻に載っている本文を、自分の言葉に直して確定できます。
  • ✨ 別案にする：同じ設定から別の切り口で次の1本を作り直します。
  • 🚀 今すぐ投稿：予定時刻を待たずにその場でXへ公開します。
3. 「⚙️ 高度な設定」でできること
  • 実務メモ・NG表現：サイトに書ききれない現場のこだわりや、絶対に使わない単語をAIに伝えられます。
  • 投稿言語・タイムゾーン：日本語発信と英語（海外向け）発信、配信時間帯の基準を切り替えられます。
  • 読者への返信（Phase 1 / Phase 2）：届いたメンションに対して「Phase 1（AI下書きを確認して1クリック送信）」が安全に使えます。自動返信（Phase 2）を使う場合のみ、X 側で別の管理用アカウントを紐付けて「自動アカウント（Automated）」ラベルを表示してください。
  • 複数アカウント運用：ヘッダー右の「＋ X追加」から別のXアカウントを追加できます（アカウントごとに契約・学習が分離されます）。
4. 無料トライアルと解約について

最初の14日間は無料（¥0）です。期間中に画面上部の案内バナー、または「プラン変更」内の「プランを解約する」ボタンを1回押すだけで自動更新が止まり、終了日までそのまま無料でお試しいただけます。
